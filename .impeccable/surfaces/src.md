## Direction contract

THESIS: WellSync is not a list of tasks — it's a live departures board for your day, where every task is a "service" ranked by when it needs to leave, cascading and re-flipping the instant priorities (or your onboarding profile) change. Refuses the category-default soft-gradient card-stack to-do app, and refuses cold enterprise-dashboard sterility.

OWN-WORLD: Charcoal board ground (never pure black — stays warm), warm off-white flap-letter ink. Full named-role palette drawn from real transit-signal color, not decoration: **Amber** (WellSync's legacy yellow, refined) = urgent / high-priority / "departing now" lamp. **Signal Green** = completed / on-time confirmation. **Signal Coral-Red** = overdue / cancelled / delete-quadrant. **Steel Cyan** = informational / scheduled / upcoming state. Each role is functional (priority, completion, urgency, category-adjacent state), never arbitrary decoration. IBM Plex Mono for flap-cell data (times, counts, tabular numerals); IBM Plex Sans for task titles and body copy.

STORY: Opening the Dashboard, the user sees their day as a board of departures — "next up" cascades to the top row, large and unmissable. Adding a task drops a new row in with a flip. Completing one flips it out in signal green. An overdue task's row dims to coral. The Smart Scheduler's re-ranking becomes visible and trustworthy because the user watches it happen, row by row.

FIRST VIEWPORT: Dashboard — greeting header, then one hero "departures" row at large scale showing the #1 recommended task (flap-cell time + title, amber lamp if urgent), a compact multi-row board beneath ranking the next 4-5 tasks, the progress ring recast as a small on-time/lamp indicator, floating add-task action styled as a board control switch.

FORM: Rail concourse split-flap departures board (challenger from catalog, won both axes vs. the assigned campus-wayfinding-signage direction on audience identification and product clarity — fused with donations from festival lineup poster's pure type-scale hierarchy for priority, and named-phase + pattern state signaling for urgency, never color alone). Seed key: 84ef8832.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
